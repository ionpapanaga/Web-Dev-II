# Gaming Tournament Web Refresher

### Reflection
During this task, the setting up of the semantic HTML5 structure and building the layout with CSS Flexbox are quite straightforward, as the structure followed a standard landing page design. 

The main challenge was fine-tuning the media queries so the tournament cards and navigation get aligned smoothly for both mobile and desktop viewports without horizontal scrolling. It was also about ensuring that the JavaScript event listener handled DOM updates without console errors.

In Web Development II, the key skill I want to improve is writing modular, component-based code and mastering state management during the transition into modern frameworks like React.
